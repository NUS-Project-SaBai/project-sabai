## Introduction

The Medication Stock page handles the medication stock. The page contains two buttons to configure the medication brands and medication active ingredients, both whose product documentation lies in a different page.

## Adding Medication Stock

To add a stock, an 'Add Stock' button is on the top right of the screen. Upon clicking the button, a modal will display on the screen. The fields are:
- Location*: Free-text
- Quantity*: Positive integer only
- Expiry date*: Date picker
- Brand + Active Ingredient*: Dropdown, containing the medication brands previously configured in the medication-brands page.
- Status*: Dropdown (active, discarded, donated, dispensed, reserved)
- Remarks: Free-text

Where "*" denotes required fields. Clicking the 'Save' button while any of the required fields are missing will result in error messages being displayed.
